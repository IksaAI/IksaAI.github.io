03

安裝

  1. 下載並打開 DMG

    下載 EQalert {{version}}，打開下載好的 EQalert-{{version}}.dmg。

  2. 把 EQalert 拖到「應用程式」

    在打開的視窗裡，把 EQalert 圖示拖到右邊的「Applications」資料夾。

  3. 第一次打開：允許執行

    EQalert 目前還沒有經過 Apple 公證，所以第一次打開時 macOS 會擋下來。這是正常的，照下面做一次，之後就能直接打開。

    macOS 15 以上（Sequoia、Tahoe）
    1. 在「應用程式」裡打開 EQalert，出現「Apple 無法驗證⋯」的視窗時按「完成」。
    2. 打開「系統設定」→「隱私權與安全性」，捲到最下面的「安全性」。
    3. 在「已阻擋 EQalert⋯」旁邊按「強制打開」，輸入密碼，再按一次「強制打開」。
    macOS 14 Sonoma
    1. 在「應用程式」裡對 EQalert 按右鍵（或 Control＋點按），選「打開」。
    2. 在跳出的視窗裡再按一次「打開」。
    會用終端機的話：一行解決
    xattr -dr com.apple.quarantine /Applications/EQalert.app

  4. 允許通知與定位

    通知用來提醒你新的地震，定位用來計算你與震央的距離和你這裡的預估震度。之後可以在「設定」（⌘,）調整提醒門檻、聲音和語言。

  1. 下載並執行安裝程式

    下載 EQalert {{exeVersion}}，執行下載好的 {{exeName}}。

  2. 出現「Windows 已保護您的電腦」：仍要執行

    EQalert 目前還沒有程式碼簽章，所以第一次執行時 Windows 會擋下來。這是正常的：點「其他資訊」，再按「仍要執行」。

  3. 照安裝精靈完成安裝

    預設只裝給你自己的帳號，不需要系統管理員權限。裝好後 EQalert 會常駐在系統匣，登入 Windows 時自動啟動（可以在設定裡關掉）。

  4. 允許通知與定位

    通知用來提醒你新的地震。定位用來計算你與震央的距離和你這裡的預估震度，要在 Windows 的「設定」→「隱私權與安全性」→「位置」打開「讓桌面應用程式存取您的位置」；不想開定位，也可以手動選城市。之後可以在「設定」（Ctrl+,）調整提醒門檻、聲音和語言。
